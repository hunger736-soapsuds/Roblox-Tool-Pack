## FAQ

### What is XCutors?

XCutors is a curated desktop application that bundles several popular Roblox script executors — Volt, Synapse Z, Potassium, and Wave — together with a universal loader so you can switch between them from one clean interface.

### Is XCutors free to use?

Yes. XCutors itself is completely free and open-source. Some individual bundled executors may require a separate licence; check each executor's documentation for details.

### Which Windows versions are supported?

XCutors officially supports Windows 10 (build 1903+) and Windows 11. Older versions of Windows may work but are not guaranteed.

### Do I need to disable my anticomponent?

Because executors interact with the Roblox client at a low level, some anticomponent software may flag them as false positives. You may need to add an exclusion for the XCutors folder. Always download from the official GitHub repository.

### How do I update the executors?

XCutors checks for updates automatically on launch. You can also open the Settings tab and click 'Check for Updates' at any time to pull the latest versions.

### Can I add my own executor to the collection?

Absolutely. Place the executor's files in the Executors folder inside your XCutors installation directory, then add an entry in executors.json following the template provided in the README.

### The 'Attach' button is greyed out — what do I do?

Make sure Roblox is open and fully loaded. If the problem persists, try running XCutors as administrator and ensure no other injection tools are active.

### Where can I find scripts to run?

XCutors ships with a built-in script hub containing popular community scripts. You can also paste any Lua script directly into the editor tab or load saved scripts from your library.

### Is there a Discord or community channel?

Yes — join our community via the Discord link in the repository sidebar for support, script sharing, and update announcements.
